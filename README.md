# SALES-DATA-ANALYSIS


# Sales Analytics Project

## Overview

This project analyzes sales data using Python, SQL, and Power BI to identify business insights related to revenue, profit, customer behavior, and product performance.

---

# Tools Used

- Python
- Pandas
- Seaborn
- Matplotlib
- SQL
- Power BI

---

# Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Data Visualization
4. SQL Business Analysis
5. Power BI Dashboard Creation
6. Business Insights Generation

---

# Datasets Used

- sales
- customers
- products
- stores
- calendar

---

# Key Analysis Performed

## Revenue Analysis
- Total Revenue

## Product Analysis
- Top Selling Products
- Profit by Category

## Customer Analysis
- Revenue by Gender

- Customer segments show different purchasing behavior
